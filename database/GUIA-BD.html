📦 SGPMRJA · Base de Datos

Guía: subir y bajar la base de datos

Estándar del equipo con MySQL 8. Exportar e importar la BD del sistema con un solo comando, igual para todos y compatible con producción.

1 · Requisitos 2 · Bajar la BD 3 · Subir la BD 4 · Problemas 5 · Alternativa
⚠️ Regla de oro: usá solo los scripts de la carpeta database/ para exportar/importar. No uses phpMyAdmin ni el mysqldump de XAMPP/MariaDB — generan SQL incompatible que falla al importar en MySQL 8 (tablas sin AUTO_INCREMENT, sintaxis MariaDB, etc.).

1 Requisitos (una sola vez)

1.1 · Instalar MySQL 8

  • Instalá MySQL Community Server 8.0 y anotá la contraseña de root.
  • Agregá la carpeta bin al PATH del sistema: C:\Program Files\MySQL\MySQL Server 8.0\bin si no lo hacés, los scripts igual la buscan ahí
🐘 ¿Tenés XAMPP? Su MySQL/MariaDB ocupa el puerto 3306. Lo más prolijo: pará el MySQL de XAMPP desde el panel, destildá su autostart y dejá MySQL 8 en el 3306. (Si preferís, dejá XAMPP y poné MySQL 8 en otro puerto, ej. 3308, y ajustá DB_PORT en el .env.)

1.2 · Verificar que responde MySQL 8

Cualquier SO
mysql --user=root -p -e "SELECT VERSION();"

Debe imprimir 8.0.xx. Si dice 10.x-MariaDB, estás pegándole a XAMPP, no a MySQL 8.

1.3 · Configurar el .env

En la raíz del proyecto, dejá la sección de BD así:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306              # el puerto de TU MySQL 8
DB_DATABASE=sistema_atlantico
DB_USERNAME=root
DB_PASSWORD=tu_password   # la contraseña de root de MySQL 8
✅ El .env es local de cada máquina y no se sube al repo: cada uno pone su puerto y contraseña sin afectar a los demás.

2 Bajar la BD desde el repo (importar)

Cada vez que quieras la base de datos al día:

Windows
git pull
powershell -ExecutionPolicy Bypass -File database\import-db.ps1
Linux / Mac
git pull
bash database/import-db.sh

El script crea la base sistema_atlantico (si no existe) e importa el dump. Después levantá la app:

php artisan config:clear
php artisan serve

Verificar que quedó bien

php artisan db:show
✅ Debe decir MySQL 8, host 127.0.0.1, base sistema_atlantico y la cantidad de tablas.

3 Subir la BD al repo (exportar)

Cuando hagas cambios en datos o esquema y quieras compartirlos:

Windows
powershell -ExecutionPolicy Bypass -File database\export-db.ps1
Linux / Mac
bash database/export-db.sh
Luego, en cualquier SO
git add database/sistema_atlantico.sql
git commit -m "chore(db): actualizar dump"
git push
📝 El script genera database/sistema_atlantico.sql en formato MySQL 8 nativo, idéntico sin importar quién lo corra.

4 Solución de problemas

SíntomaCausa probableSolución
mysql no se reconoce… / command not found MySQL 8 no está en el PATH Agregá …\MySQL Server 8.0\bin al PATH y abrí una terminal nueva.
VERSION() devuelve 10.x-MariaDB Estás pegándole a XAMPP, no a MySQL 8 Pará XAMPP MySQL o corregí DB_PORT en el .env.
Access denied for user 'root' Contraseña incorrecta en el .env Poné la contraseña real de root de MySQL 8 en DB_PASSWORD.
Field 'id' doesn't have a default value al usar la app Importaste un dump viejo de phpMyAdmin Reimportá con import-db.ps1 el dump del repo (es MySQL 8 nativo).
El 3306 está ocupado al iniciar MySQL 8 XAMPP MySQL tomó el 3306 primero Pará XAMPP MySQL y destildá su autostart, o usá otro puerto.
Error 500 al entrar al dashboard tras git pull Falta regenerar el autoload de Composer composer dump-autoload + php artisan optimize:clear.

5 Alternativa sin importar dump (opcional)

Para reconstruir la BD desde cero con migraciones + datos de catálogo, sin depender del .sql:

php artisan migrate:fresh --seed
Crea el esquema desde las migraciones y carga los seeders. Útil si querés un entorno limpio.
