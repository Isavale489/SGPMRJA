Convenciones generales: todas las claves primarias son id BIGINT UNSIGNED autoincrementales salvo indicación contraria. Los campos created_at / updated_at son las marcas de tiempo estándar de Laravel, y deleted_at implementa la eliminación lógica (soft delete): un valor NULL indica que el registro está activo. Los montos monetarios se expresan en dólares (USD) salvo que el campo indique bolívares (Bs).
