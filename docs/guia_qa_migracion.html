Parte 1 · Preparar y levantar el sistema

Esto se hace una sola vez, en tu computadora. El sistema corre en tu PC y lo abres desde el iPhone por el Wi-Fi de tu casa, como si fuera una página web.

Elige tu sistema operativo y los comandos se ajustan:

1 Lo que necesitas

  • PHP 8.3 o más nuevo. Es obligatorio: el sistema ahora usa Laravel 13 y no arranca con PHP 8.2 o anterior.
  • Composer, Git y MySQL 8 (el mismo de siempre).
  • La computadora y el iPhone conectados al mismo Wi-Fi.
  • No necesitas Node ni npm: la parte visual ya viene compilada en el repositorio (public/build).

Abre una terminal (PowerShell) y revisa la versión de PHP:

php -v

Debe decir PHP 8.3.x o 8.4.x.

Si dice 8.2 o menos: el XAMPP más reciente trae PHP 8.2, así que no sirve. Instala Laragon con PHP 8.3, o descarga PHP 8.3 para Windows y pon su carpeta en el PATH. Si tienes dudas, escríbele a Emmanuel antes de seguir.

Si dice 8.2 o menos: instala PHP 8.3 con sus extensiones (mbstring, xml, curl, mysql, zip, gd, intl, bcmath) y vuelve a revisar.

2 Bajar los cambios

Entra a la carpeta del proyecto (cámbiala por la ruta donde lo tengas):

cd C:\laragon\www\SGPMRJA
cd ~/SGPMRJA

Revisa si tienes cambios propios sin guardar:

git status

Si aparecen archivos modificados que no quieres perder, guárdalos aparte. Si no aparece nada, salta este comando:

git stash push -m "mis cambios antes de la QA"

Ahora cambia a la rama dev y baja lo último:

git fetch origin
git checkout dev
git pull origin dev

Comprueba que quedaste al día:

git log --oneline -1

Debe mostrar un merge reciente, por ejemplo «Merge pull request #73».

3 Instalar las dependencias de PHP

La migración cambió muchas librerías, así que este paso es obligatorio aunque ya lo hayas hecho antes:

composer install

Tarda uno o dos minutos. Si termina con un error de versión de PHP, vuelve al paso 1.

4 Base de datos

Vas a usar el archivo .env que ya tienes en la carpeta del proyecto. Ábrelo y confirma que los datos de MySQL sean los de tu computadora:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sistema_atlantico
DB_USERNAME=root
DB_PASSWORD=tu_clave

En el mismo .env, revisa también estas dos líneas (si no existen, agrégalas):

APP_DEBUG=true
SESSION_SECURE_COOKIE=false

La segunda es importante: sin ella, el iPhone no mantiene la sesión abierta, porque entra por http y no por https.

Importar la base de datos del repositorio

Ojo: esto reemplaza lo que tengas en tu base de datos local por la copia del repositorio. Si tienes datos de prueba propios que quieras conservar, avísale a Emmanuel antes.

Con MySQL encendido, corre el script del equipo. Crea la base de datos (el nombre lo toma del .env) e importa el archivo database/sistema_atlantico.sql:

powershell -ExecutionPolicy Bypass -File database\import-db.ps1
bash database/import-db.sh

Después aplica cualquier cambio de estructura pendiente:

php artisan migrate

Lo normal es que diga Nothing to migrate (el archivo ya viene al día). Si te pregunta si quieres continuar en producción, responde que no y revisa que tu .env diga APP_ENV=local.

Nunca corras php artisan test en tu computadora con esta base de datos. Las pruebas automáticas borran datos. No hacen falta para esta QA.

5 Limpiar cachés y enlazar las imágenes

php artisan optimize:clear
php artisan storage:link

El segundo comando conecta la carpeta de fotos (avatares, imágenes de productos). Si dice que el enlace ya existe, está bien.

6 Levantar el sistema en tu red local

Primero averigua la IP de tu computadora en el Wi-Fi:

ipconfig

Busca el adaptador Wi-Fi y la línea Dirección IPv4. Es algo como 192.168.1.105.

# Linux
hostname -I
# Mac
ipconfig getifaddr en0

Toma la primera dirección que empiece por 192.168. o 10..

Ahora arranca el servidor escuchando en toda la red, no solo en tu PC:

php artisan serve --host=0.0.0.0 --port=8000

Deja esa terminal abierta mientras pruebas. Para apagar el sistema, presiona Ctrl + C en ella.

Comprueba primero en la computadora: abre el navegador en http://localhost:8000. Debe salir la pantalla de inicio de sesión, con fondo azul.

La primera vez, Windows puede preguntar si permites que PHP se comunique por la red. Marca Redes privadas y acepta. Si ya lo rechazaste antes, busca «Firewall de Windows Defender» → «Permitir una aplicación» y habilita php.exe en redes privadas.

Parte 2 · Antes de probar

Cómo usar esta guía

  • Lee esta guía en la computadora y prueba en el iPhone. Cuando un caso diga «también en PC», repítelo en el navegador de la computadora.
  • Sigue los casos en orden. Varios dependen del anterior: por ejemplo, el pedido se crea a partir de la cotización que hiciste antes.
  • En cada caso marca Funciona, Falla o No aplica. Si falla, escribe en la nota qué pasó. Las marcas se guardan solas en este navegador, así que puedes cerrar la guía y seguir otro día.
  • Al terminar, toca Generar reporte arriba, copia el texto y envíaselo a Emmanuel junto con tus capturas de pantalla.
  • Los nombres de ejemplo (clientes, productos) son de la base de datos del repositorio. Si alguno no aparece, usa cualquier otro parecido.

Conocer el sistema en 5 minutos

El SGPMRJA es el sistema de gestión de pedidos de Manufacturas R.J. Atlántico, un taller de bordados y uniformes. Con él se cotiza, se vende, se fabrica y se controla el inventario.

La pantalla tiene tres partes:

  • Barra superior azul oscuro:
    • a la izquierda: el logo y el botón que encoge el menú;
    • en el centro: la fecha y la Tasa BCV del día;
    • a la derecha: el botón de tema claro/oscuro, la campana de notificaciones y tu usuario.
    En el iPhone, el logo y el menú se abren con el botón ☰.
  • Menú lateral con los módulos, agrupados en tres secciones. Cada sección tiene su color:
  • Contenido: título de la página, botones de acción, filtros y tabla.
SecciónColorMódulos
Gestión GeneralAzul marinoClientes, Productos (Catálogo, Atributos, Colores), Proveedores, Insumos, Recursos Humanos (Empleados, Departamentos, Cargos)
Gestión OperativaVerde esmeraldaCotizaciones, Pedidos, Orden de Producción, Control de Calidad, Movimientos (Movimientos de Insumos, Compras)
Consultas y ReportesCelesteProducción, Eficiencia, Consumo de Insumos, Rendimiento de Empleados, Reportes Generales
AdministraciónAzul marinoDesde tu usuario (arriba a la derecha) → Configuración: parámetros, impuestos, Usuarios, Mi perfil, Roles y permisos

El recorrido de un trabajo, de principio a fin:

  1. Cotización: el cliente pide precio. Se arma con productos, tallas, colores y bordados. Nace Pendiente y luego se Aprueba.
  2. Pedido: solo nace de una cotización aprobada. Exige un abono mínimo (50 % por defecto) y una fecha de entrega. La cotización queda Convertida.
  3. Orden de producción: se crean desde el pedido. Dicen cuántas unidades se fabrican, qué empleados las hacen y qué insumos se usan.
  4. Avance: se registran las unidades producidas. Al completar todas, la orden pasa sola a Finalizado.
  5. Control de calidad: se inspecciona cada orden finalizada. Si hay defectuosas, la orden vuelve a producción.
  6. Pedido completado: cuando todas sus órdenes terminan, el pedido pasa solo a Completado y se registra el pago del saldo.

En paralelo, Compras registra lo que se le compra a los proveedores (sube el inventario de insumos), y Movimientos registra las salidas manuales de insumos.

Reglas de negocio que debes vigilar en todo el sistema

  • Todo monto en dólares ($) va con su equivalente en bolívares (Bs), y la tasa siempre muestra su fecha, por ejemplo «Tasa BCV (30/09/2026): Bs 859,06». Si ves un monto en $ sin Bs, o una tasa sin fecha, es un fallo.
  • Los estados tienen colores fijos: Pendiente en naranja, En Proceso o Procesando en azul celeste, Aprobada, Finalizado y Completado en verde, Convertida en morado, Cancelado o anulado en rojo, y borrador o Vencida en gris.
  • Cambios sin guardar: si escribes en un formulario e intentas salir (cerrar el diálogo, tocar otro módulo o el botón Atrás), el sistema debe preguntarte con su propio diálogo, con los botones «Descartar» y «Seguir editando».
  • Nada se debe salir de la pantalla del iPhone: la página no debe poder moverse de lado. Una tabla ancha sí puede deslizarse dentro de su recuadro.
  • Los usuarios nunca se borran, solo se inhabilitan. Clientes, proveedores, empleados e insumos tampoco: se inhabilitan y pasan al historial.

A. Acceso al sistema General

ACC-01

Iniciar sesión

iPhone · también en PC
  1. Abre http://TU-IP:8000. Sale la pantalla «Iniciar sesión» con fondo azul y el logo.
  2. Escribe admin@gmail.com y una contraseña equivocada. Toca Iniciar sesión.
  3. Ahora escribe la contraseña correcta, sistemas, y entra.
Esperado: con la clave equivocada sale un mensaje de error debajo del campo, sin recargar toda la página. Con la correcta entras a Inicio. El diseño se ve bien en el iPhone, sin nada cortado.
ACC-02

Mostrar y ocultar la contraseña, y «Recuérdame»

iPhone
  1. Cierra sesión (tu usuario arriba a la derecha → Cerrar sesión).
  2. En el inicio de sesión, escribe la contraseña y toca el ícono del ojo del campo.
  3. Marca Recuérdame, entra, cierra Safari por completo y vuelve a abrir la dirección.
Esperado: el ojo muestra y oculta la contraseña. Con «Recuérdame», al volver sigues con la sesión abierta.
ACC-03

Primera entrada del supervisor: configurar preguntas de seguridad

iPhone
  1. Cierra sesión y entra con supervisor@gmail.com / sistemas.
  2. El sistema te debe llevar a Mi perfil pidiendo configurar las preguntas de seguridad.
  3. Elige 3 preguntas distintas, escribe respuestas que recuerdes (anótalas) y guarda.
Esperado: no puedes ir a otro módulo hasta configurar las preguntas. Al guardar sale un aviso verde de éxito y ya puedes navegar. El supervisor ve menos módulos en el menú que el administrador.
ACC-04

Recuperar la contraseña con las preguntas de seguridad

iPhone
  1. Cierra sesión. En el inicio de sesión toca ¿Olvidaste tu contraseña?.
  2. Elige recuperar con preguntas de seguridad y escribe supervisor@gmail.com.
  3. Responde las 3 preguntas del caso anterior.
  4. Pon una contraseña nueva (anótala) y confírmala.
  5. Entra con la contraseña nueva.
Esperado: con respuestas correctas te deja poner una contraseña nueva y entrar con ella. Con una respuesta equivocada debe avisarte; tras varios intentos fallidos, bloquea la recuperación un tiempo.

Al terminar, vuelve a dejar la contraseña del supervisor en sistemas desde Mi perfil → Contraseña, para que los demás casos funcionen igual.

ACC-05

Cerrar sesión

iPhone · también en PC
  1. Toca tu usuario arriba a la derecha → Cerrar sesión.
  2. Con la sesión cerrada, toca el botón Atrás del navegador.
Esperado: vuelves al inicio de sesión. Con Atrás no puedes volver a ver pantallas del sistema sin entrar de nuevo.

E. Flujo principal de venta y producción Verde esmeralda

Estos casos van en cadena: crea la cotización, conviértela en pedido, fabrícalo y entrégalo. Anota los números (#) que te va dando el sistema.

COT-01

Crear una cotización completa

iPhone
  1. Abre Gestión Operativa → Cotizaciones y toca Nueva cotización.
  2. Paso 1 · Cliente: toca Siguiente sin elegir. Luego busca un cliente (por ejemplo Julian), elígelo y marca una prioridad.
  3. Paso 2 · Productos: toca Siguiente sin productos. Luego toca Abrir catálogo:
    • elige un producto (por ejemplo, «Chemise»);
    • en Variante, elige las opciones hasta que diga «Variante encontrada»;
    • en Configurar, elige un color y pon cantidades en dos tallas;
    • toca Agregar a la cotización.
  4. En la fila del producto, toca el botón de Bordados, marca una ubicación y toca Aplicar bordados.
  5. Paso 3 · Resumen: revisa los totales y toca Crear cotización.
Esperado:
  • Sin cliente o sin productos no deja avanzar y dice por qué.
  • Arriba aparece un chip con el cliente.
  • El precio unitario se propone solo.
  • El resumen muestra subtotal, IVA y total en $ y Bs, con la tasa y su fecha.
  • Al crear, sale «Cotización #N creada» y se abre su detalle como Pendiente, con la prioridad que elegiste.
COT-02

Ver, editar, PDF y aprobar la cotización

iPhone · también en PC
  1. En la lista, toca el ojo de tu cotización y recorre sus pasos.
  2. Toca ⋮ → Editar, cambia una cantidad y guarda.
  3. Toca ⋮ → Ver PDF.
  4. Toca ⋮ → Aprobar y confirma.
Esperado:
  • Los cambios se guardan y sale «Cotización #N actualizada».
  • El PDF se abre en otra pestaña, con los datos correctos.
  • Al aprobar, el estado cambia a Aprobada (verde) y aparece la acción «Convertir a pedido».
COT-03

Cancelar y reactivar una cotización

iPhone
  1. Crea una segunda cotización rápida (un producto, una talla).
  2. Toca ⋮ → Cancelar cotización y confirma.
  3. Toca ⋮ → Reactivar (Pendiente).
  4. Prueba los filtros por estado y por fechas de la lista.
Esperado: el estado pasa a Cancelada (rojo) y luego vuelve a Pendiente. Las acciones del menú cambian según el estado. Los filtros funcionan.
PED-01

Convertir la cotización en pedido

iPhone
  1. En Cotizaciones, en la cotización Aprobada de COT-02, toca ⋮ → Convertir a pedido.
  2. Paso 1: revisa la cotización y el cliente. Toca 30 días hábiles para proponer la entrega.
  3. Paso 2: revisa los productos, que vienen de la cotización y no se pueden editar.
  4. Paso 3 · Pago:
    • toca Siguiente sin pagos: debe avisar que no alcanza el mínimo;
    • toca Efectivo: propone el 50 % del total;
    • prueba también agregar un pago por transferencia y elegir un banco.
  5. Paso 4 · Resumen: revisa «Saldo por cobrar» y toca Crear pedido.
Esperado:
  • No deja crear el pedido sin el abono mínimo ni sin fecha de entrega.
  • Sale «Pedido #N creado» y se abre su detalle, en estado Pendiente.
  • En Cotizaciones, la cotización ahora dice Convertida (morado).
PED-02

Detalle y edición del pedido

iPhone · también en PC
  1. En Pedidos, revisa la columna «Abonado» con su barra de progreso.
  2. Abre el detalle (ojo) de tu pedido. Arriba deben verse el estado y quién lo creó.
  3. Toca ⋮ → Editar pagos y entrega. Cambia la prioridad y guarda.
  4. Toca ⋮ → Ver PDF.
Esperado:
  • En el encabezado verde del detalle, el estado y las iniciales se leen bien.
  • Al editar salen chips con el cliente y el creador.
  • Los cambios se guardan y el PDF abre.
ORD-01

Crear las órdenes de producción del pedido

iPhone · también en PC
  1. Abre Gestión Operativa → Orden de Producción y toca Nueva orden.
  2. Elige tu pedido de la lista (sale con el nombre del cliente).
  3. Toca Siguiente. En la asignación, prueba Dividir para repartir las unidades en dos órdenes.
  4. Toca Siguiente sin marcar empleados: debe pedir el equipo. Marca al menos un empleado en cada orden.
  5. Revisa los insumos calculados y el resumen. Toca Crear 2 órdenes (o el número que corresponda).
Esperado:
  • Los pedidos que no cumplen el abono mínimo (o que ya tienen todo asignado) aparecen bloqueados y no se pueden elegir.
  • «Dividir» reparte las unidades.
  • Los insumos se calculan por unidad, y el resumen avisa si falta existencia.
  • Se crean las órdenes y sale el aviso de éxito.
ORD-02

Ver la orden: resumen, etapas y avance

iPhone · también en PC
  1. En la lista de órdenes, toca Ver órdenes en la fila de tu pedido.
  2. Toca el ojo de una orden. Arriba debe verse un resumen con la foto del producto (o un ícono), el nombre y una barra de avance.
  3. Recorre sus pasos: Orden, Insumos y Progreso.
  4. Ciérrala. En ⋮ → Etapas, agrega una etapa (por ejemplo, «Corte») y cambia su estado.
  5. En ⋮ → Registrar avance, pon una parte de las unidades y registra.
Esperado: el avance se registra con aviso verde y la orden pasa a En Proceso. El pedido pasa a Procesando. La barra de avance se actualiza.
ORD-03

Terminar la producción

iPhone
  1. En cada orden de tu pedido, usa Registrar avance con las unidades que faltan.
  2. Intenta registrar más unidades de las que faltan.
Esperado: no permite pasarse de la cantidad. Al completar todas las unidades, la orden pasa sola a Finalizado y aparece en Control de Calidad.
CAL-01

Control de calidad: rechazo (vuelve a producción)

iPhone
  1. Abre Gestión Operativa → Control de Calidad. Tu pedido debe aparecer con sus órdenes pendientes de inspección.
  2. Toca Ver órdenes y luego Inspeccionar en una orden.
  3. Suma 2 defectuosas con el botón +. Debe decir «Rechazo: la orden vuelve a producción».
  4. Toca Registrar rechazo sin motivo; luego escribe un motivo y regístralo.
Esperado:
  • Las defectuosas se reparten solas entre los empleados de la orden.
  • Sin motivo, no deja registrar.
  • Al registrar, la orden sale de la cola y vuelve a producción con las unidades rechazadas por rehacer.
CAL-02

Control de calidad: aprobación

iPhone
  1. Vuelve a Orden de Producción y registra el avance de lo rechazado hasta completar de nuevo.
  2. En Control de Calidad, inspecciona otra vez y deja 0 defectuosas. Regístralo.
  3. Inspecciona también la otra orden con 0 defectuosas.
Esperado: con 0 defectuosas la inspección queda como conforme. Cuando no quedan órdenes por inspeccionar, la cola dice que no hay órdenes pendientes.
PED-03

Pedido completado y pago del saldo (entrega)

iPhone
  1. Abre Pedidos: tu pedido debe estar en Completado (verde).
  2. Toca ⋮ → Registrar pago y registra el saldo pendiente.
  3. Abre el detalle del pedido.
Esperado: el pedido se completó solo al terminar todas sus órdenes. Al pagar el saldo, «Abonado» llega a 100 % y la barra se pone verde. El detalle muestra los pagos con su fecha, montos en $ y Bs.
PED-04

Cancelar y eliminar pedidos

iPhone
  1. Crea una cotización rápida, apruébala y conviértela en pedido (sin crear órdenes).
  2. En ese pedido toca ⋮ → Eliminar y confirma.
  3. Vuelve a Cotizaciones.
Esperado: el pedido se elimina y su cotización vuelve a Aprobada, así que se puede convertir otra vez. En un pedido con producción iniciada no debe dejar eliminar.

F. Compras e inventario Verde esmeralda

COM-01

Registrar una compra en borrador

iPhone · también en PC
  1. Abre Movimientos → Compras y toca Nueva compra.
  2. Paso 1: elige un proveedor y escribe un número de factura. La tasa del día se llena sola.
  3. Paso 2: agrega dos insumos con su cantidad. Revisa el costo en Bs propuesto y quítale el IVA a uno con su interruptor.
  4. Paso 3: revisa el resumen y toca Guardar borrador.
Esperado: el total se recalcula al cambiar el IVA. Sale «Borrador de compra #N guardado». En la lista aparece como borrador (gris). La existencia de los insumos no cambia todavía.
COM-02

Ver la compra (vista de recibo) y procesarla

iPhone · también en PC
  1. Toca el ojo de tu compra.
  2. Revisa el recibo: proveedor arriba, y factura, fecha y tasa BCV en líneas punteadas a la derecha. Abajo, el detalle de insumos y la barra de totales con «Total a pagar» resaltado en verde.
  3. Toca Procesar y confirma.
  4. Ve a la pestaña Existencias y busca uno de los insumos.
Esperado: la compra pasa a recibida (verde) y la existencia del insumo sube en la cantidad comprada. En el iPhone, la tabla del recibo se puede deslizar de lado dentro de su recuadro.
COM-03

Anular y clonar una compra

iPhone
  1. En la compra recibida, toca ⋮ → Anular y confirma.
  2. Revisa en Existencias que el insumo volvió a su cantidad anterior.
  3. Ve a la pestaña Anuladas, toca ⋮ → Clonar como borrador.
Esperado:
  • Al anular, el stock se revierte y la compra pasa a Anuladas con quién la anuló.
  • Clonar crea un borrador nuevo igual.
  • Una compra ya clonada muestra «Ya fue clonada».
MOV-01

Movimientos de insumos: salida manual

iPhone · también en PC
  1. Abre Movimientos → Movimientos de Insumos.
  2. Revisa la lista: entradas (por compras) y salidas (por producción), con su existencia antes → después.
  3. Toca Registrar salida, elige un insumo y una cantidad mayor a la existencia; luego, una cantidad válida.
  4. Abre Alertas y Rotación.
Esperado: solo se registran salidas manuales: las entradas vienen de Compras. No deja sacar más de lo que hay. Alertas muestra los insumos bajo su mínimo; Rotación, cuánto se mueve cada insumo.

H. Administración Azul marino

ADM-01

Configuración del sistema

iPhone · también en PC
  1. Toca tu usuario arriba a la derecha → Configuración.
  2. Revisa los parámetros por módulo (por ejemplo, días de vigencia de las cotizaciones y abono mínimo de los pedidos).
  3. Cambia el abono mínimo a 40 %, guarda, y comprueba en un pedido nuevo que el mínimo propuesto cambió. Después déjalo en 50 %.
  4. En Impuestos, intenta eliminar el IVA; luego agrega un impuesto de prueba y elimínalo.
Esperado: los cambios se guardan y se reflejan en los formularios. El IVA está protegido y no se puede eliminar. Los demás impuestos sí, con confirmación.
ADM-02

Usuarios

iPhone · también en PC
  1. En Configuración, toca Usuarios.
  2. Agrega un usuario con tu correo de prueba, el rol Supervisor y una contraseña. Prueba también una contraseña débil.
  3. En ⋮, prueba Editar, Inhabilitar y Habilitar.
  4. Prueba Resetear contraseña en tu usuario de prueba y entra con él.
Esperado:
  • La contraseña débil se rechaza con un mensaje claro.
  • Un usuario inhabilitado no puede entrar.
  • Tras resetear, al entrar el sistema obliga a cambiar la contraseña.
  • No existe la opción de eliminar usuarios.
ADM-03

Roles y permisos

PC (más cómodo)
  1. En Configuración, toca Roles y permisos.
  2. Toca Nuevo rol, ponle un nombre (por ejemplo, «Prueba QA») y créalo.
  3. En la pestaña Permisos, marca «Clientes: Crear»: «Clientes: Ver» se marca solo. Marca algunos permisos de Gestión Operativa y guarda.
  4. Asigna ese rol a tu usuario de prueba (ADM-02), entra con él y revisa el menú.
  5. Vuelve como admin, quita el rol del usuario y elimina el rol.
Esperado:
  • Cada sección de la matriz tiene su color.
  • El usuario con el rol nuevo ve solo los módulos permitidos; si escribe a mano la dirección de otro módulo, recibe un error de acceso.
  • Un rol con usuarios no se puede eliminar.
ADM-04

Mi perfil

iPhone
  1. Tu usuario → Configuración → Mi perfil.
  2. Cambia tu nombre y guarda.
  3. Sube una foto de perfil desde el iPhone (cámara o galería).
  4. Abre la sección de contraseña y prueba poner la contraseña actual equivocada.
Esperado:
  • La foto aparece en tu avatar de la barra superior.
  • Con la contraseña actual equivocada sale un mensaje claro en español, no un texto técnico.
  • Al cambiar la contraseña, se cierran las sesiones abiertas en otros dispositivos.

Cómo reportar lo que encuentres

Para cada fallo, escribe en la nota del caso y toma una captura de pantalla. Incluye:

  1. Dónde: módulo y pantalla, por ejemplo «Pedidos → Nuevo pedido, paso 3».
  2. Qué hiciste: los pasos exactos.
  3. Qué esperabas y qué pasó.
  4. En qué: iPhone o PC, y si estabas en tema claro u oscuro.
  5. Si salió una pantalla de error, la captura completa.

Al terminar, toca Generar reporte (arriba). Arma un texto con el resumen y todos los casos con falla y sus notas: cópialo y envíaselo a Emmanuel junto con las capturas.
